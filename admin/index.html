Khai Báo Nhanh Qua LINE

Tự động thêm Admin chỉ với 1 tin nhắn

Để cấp quyền Admin cho bất kỳ ai (hoặc chính bạn):

  1. Mở ứng dụng LINE trên điện thoại/máy tính.
  2. Tìm kiếm và nhắn tin riêng trực tiếp cho BOT chữ: admin
  3. BOT sẽ tự động đọc User ID của bạn và thêm vào danh sách Admin bên dưới ngay lập tức!
Không cần khởi động lại Server hay chỉnh sửa biến môi trường khi thêm Admin mới!
